# 采购管理控制台升级方案

> 历史设计说明：本方案最初采用 IndexedDB。当前实现已切换为项目共享 SQLite，一次性数据管理/迁移模块已完成并移除；现行存储行为见 [STORAGE-DESIGN.md](STORAGE-DESIGN.md)。

## 目标与约束

供应商可完整管理；采购申请提供多种表单与有状态的业务流程，适合后续 E2E 测试；统一管理控制台 UI。保留 Vue 3、Element Plus、IndexedDB，无后端。升级数据库时迁移已有申请，不清空用户数据。

## 实现选择

沿用 IndexedDB：已有表单和 File 附件均可直接持久化，使用版本迁移增加供应商与审批历史。localStorage 不适合现有文件附件；后端数据库超出本次范围。

复用 Element Plus 的表单、表格、分页、抽屉、弹窗等组件，不更换前端框架，不新增通用表单引擎。将现有 Desk 拆成首页、申请列表和供应商页面，让页面职责清晰。

## 供应商管理

- 列表支持关键词、启用状态、供应范围筛选、分页和空状态。
- 新建/编辑：名称、联系人、电话、邮箱、地址、供应范围（物资/服务/软件）、启用状态、备注。
- 详情抽屉展示完整资料及关联采购申请。
- 名称去除首尾空白后不可重复；必填、邮箱和联系电话在保存入口校验。
- 删除前确认；已被申请引用的供应商禁止删除，可停用。停用后不可用于新提交；历史详情保留提交时的供应商信息。
- 现有四个供应商迁移为正式记录，申请通过稳定 ID 关联。

## 三类采购申请

所有类型共享标题、部门、申请人、期望日期、优先级、供应商、事由、富文本说明与附件。创建时选择类型，分步填写、保存草稿、恢复编辑、确认后提交。

1. 物资采购：动态明细行、品名、规格、数量、单价、收货地址、联系人、是否需要安装及安装说明。
2. 服务采购：服务类别、起止日期、服务地点、交付说明、动态里程碑（名称、日期、金额）；里程碑日期须在服务期间内。
3. 软件订阅：产品名称、授权席位、每席单价、订阅月数、起始日期、自动续费、数据敏感级别；金额按席位 × 单价 × 月数计算。

金额统一以分计算，拒绝非有限数字、负数和无效数量。类型字段使用明确的数据模型；旧记录迁移成物资采购并保留其原始金额、状态和附件。

列表支持标题/编号/部门搜索、类型与状态筛选、排序和分页；详情显示类型信息、金额、附件和审批时间线。草稿可编辑、确认删除；提交后的业务数据只读。

## 演示业务规则（用户已确认）

这些是本次新增的 E2E 演示规则，不代表现有公司的采购政策：

- 提交前集中校验完整表单及供应商可用状态。
- 金额低于 10,000 元：部门审批后通过。
- 金额达到 10,000 元：部门审批通过后进入财务审批，两级通过才完成。
- 任一审批节点可驳回，驳回原因必填；申请人修改后可再次提交，保留全部历史。
- 审批工作台按当前节点办理，必须填写审批意见。界面明确说明是本地演示身份，不声称具备真实权限隔离。
- 状态与历史在同一 IndexedDB 事务中写入；重复提交、过期状态审批直接报错，不伪造成功。
- 旧的“已提交”记录保留原状态并建立对应待审批节点；不虚构已发生的审批历史。

## UI 规范

采用 ui-ux-pro-max 的企业控制台简洁网格风格建议；不使用搜索结果中与本产品无关的营销 Hero/CTA 布局。

- 深蓝灰侧栏、白色顶栏、浅灰背景；主色 #2563EB，正文 #1E293B，边框 #E2E8F0。
- 系统中文字体，无远程字体依赖；数字金额使用等宽数字，统一间距和状态语义。
- 导航：工作首页、采购申请、供应商名录、审批工作台。
- 首页显示真实统计、待办入口与最近申请，不展示虚构增长指标。
- 表单分区与步骤导航，错误靠近字段；提交有加载状态，危险操作二次确认。
- 键盘可操作、焦点可见、控件有可访问名称；窄屏调整导航与字段布局，表格在自身容器内滚动。

## 验证与完成标准

- 构建和类型检查通过。
- 真实浏览器验证供应商新增、查询、编辑、删除、引用删除限制及停用规则。
- 三种申请完整创建、金额计算、草稿恢复、刷新后搜索、详情和附件。
- 验证两级审批、金额边界、驳回重提、无效表单阻断与历史持久化。
- 验证旧版数据库迁移，不丢申请或附件。
- 检查桌面和窄屏渲染、键盘操作、空状态与错误提示。
- 更新常规 E2E 用例、AI 用例中受影响的页面与状态，以及 README。

## 实施顺序

### 审查补充：数据与验证契约

- 历史记录缺失的新字段保持为空，不生成联系人、地址或供应商电话邮箱。旧已提交申请可以查看和审批；旧草稿下次提交时补齐新的必填字段。
- 状态使用草稿、已提交、已通过、已驳回；审批阶段单独记录部门、财务或完成。驳回重提重新按当次金额确定审批路径，保留历史。
- 供应商引用检查与删除、供应商启用检查与申请提交、审批状态检查与历史写入，均在覆盖相关仓库的同一事务内执行。
- 首页重置统一恢复供应商和申请演示数据并清除审批历史，确认弹窗明确列出范围；避免留下悬空引用。
- 迁移测试从真实 v1 数据库开始，包含空供应商草稿、带附件申请和已提交申请，验证原 ID、金额、时间、状态和附件内容。
- 金额边界覆盖 9999.99/10000.00、服务里程碑合计、软件席位乘月份、小数单价和无效数值。附件验证包括下载内容。

1. 数据模型、规则测试及 IndexedDB 升级迁移。
2. 供应商增删改查及真实浏览器验证。
3. 多类型表单、列表、详情及本地审批流程。
4. 统一 UI、响应式与可访问性检查。
5. 完整回归、迁移验证、文档和最终审查。

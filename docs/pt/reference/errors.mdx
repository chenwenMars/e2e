Todo erro do runner traz uma classe e um código. A classe define o código de
saída, e o código indica a causa. Um modelo nunca escolhe nenhum dos dois.
`e2e login`, `e2e logout` e `e2e models` são a exceção, descrita em
[Códigos de saída](#exit-codes).

```ts title="tests/upgrade.e2e.ts"
import { isAgentError, test } from 'e2e';

test('upgrade to Pro', async ({ agent }) => {
  try {
    await agent.act('upgrade the workspace to Pro');
  } catch (error) {
    if (isAgentError(error) && error.code === 'STEP_TIMEOUT') {
      // the step ran out of time; the message carries the last judgment
      console.error(error.category, error.details);
    }
    throw error;
  }
});
```

## Referência

### Códigos de saída

| Classe | Código de saída |
| --- | ---: |
| test | 1 |
| configuration | 2 |
| infrastructure | 3 |
| internal | 4 |
| interrupted | 130 |

- Em uma execução mista, prevalece o código presente de maior precedência,
  `130 > 4 > 3 > 2 > 1 > 0`. O relatório mantém cada resultado individual.
- Um teste cuja limpeza falhou (um vídeo obrigatório que não foi
  finalizado, uma sessão que não fechou) sai com o código desse erro de
  limpeza, normalmente 3.
- Uma falha de asserção em um teste de preparação é uma falha de teste e pula
  os dependentes desse teste. Uma infraestrutura de preparação ausente mantém
  a sua classe, configuration ou infrastructure.
- A classe `internal` e o código de saída 4 são reservados para violações de
  invariantes do runner. Hoje, nenhum pacote oficial lança um código dessa
  classe.
- `e2e login`, `e2e logout` e `e2e models` imprimem a mensagem de uma falha
  sem o código de erro e saem com código 1, ou 130 quando um login ou um menu de seleção
  é cancelado.

| Códigos | Descrição |
| --- | --- |
| [Códigos do agente](#agent-codes) | O `code` de um `AgentError` |
| [Códigos do runner](#runner-codes) | Strings simples na saída e no relatório |
| [Erros no código de teste](#test-code-errors) | Lançados pelo código de teste |

### AgentError

`AgentError` é a falha do agente classificada pelo runner, exportada de `e2e`.

```ts
/** Runner-classified agent failure. */
export class AgentError extends Error {
  /** Closed union, assigned by the runner, never taken from model text. */
  readonly code: AgentErrorCode;
  /** The error class in the table above; it sets the exit code. */
  readonly category: 'test' | 'configuration' | 'infrastructure' | 'internal' | 'interrupted';
  readonly retryable: boolean;
  /** Structured facts: locator, expected, observed, match count, wait time. */
  readonly details: ErrorDetails | undefined;
  /** Sanitized, bounded prose; the same value as `message`. */
  readonly explanation: string;
  /** Artifact path, present only when evidence was captured and permitted. */
  readonly screenshot?: string;
  /** True when this failure reports a blocked step, not a product failure. */
  readonly blocked: boolean;
}
```

<Note>
Os arquivos de teste são carregados em um realm de módulos próprio, então
`instanceof AgentError` pode ser falso. Use `isAgentError` de `e2e` e decida
pelo `code`, como no exemplo no topo desta página.
</Note>

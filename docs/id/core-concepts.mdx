Sebuah tes menggabungkan tiga jenis langkah:

| Langkah | API | Panggilan model |
| --- | --- | --- |
| [Tujuan](#goals) | `agent.act` | Ya, kecuali [cache](/cache) memutarnya ulang |
| [Assertion](#assertions) | `agent.assert`, `agent.waitFor`, `agent.extract` | Ya |
| [Locator](#locators) | `screen` dan `expect` | Tidak |

Dengan [executor kustom](/executors), `act` dan `assert` tidak memerlukan model.

```ts title="tests/todos.e2e.ts"
import { describe, test, expect } from 'e2e';

describe('todos', () => {
  test('the Done filter shows only completed todos', async ({ app, agent, screen }) => {
    await app.open('/todos');
    await agent.act('add todos "Buy milk" and "Walk the dog"');
    await agent.act('complete "Buy milk"');
    await agent.waitFor('"Buy milk" is completed and "Walk the dog" is open');

    await screen.getByRole('tab', 'Done').tap();

    await expect(screen.getByTestId('todo')).toHaveCount(1);
    await agent.assert('the only todo listed is "Buy milk"');
  });
});
```

Setiap tes memeriksa satu perilaku dalam tiga bagian: siapkan keadaan awal,
lakukan tindakan, lalu periksa hasilnya.

Gunakan `await` pada setiap pemanggilan agent, pemanggilan screen, dan
`expect.poll`. Jika tes selesai saat sebuah langkah masih berjalan, tes gagal
dengan `STEP_NOT_AWAITED`.

## Tujuan

`agent.act` menerima satu tujuan lalu melakukan tindakan yang diperlukan.
Pemanggilan selesai saat tujuan tercapai dan melempar error jika gagal.

```ts
await agent.act('complete checkout with the test card');
await agent.act('invite {email} as an editor', { params: { email: 'ada@example.test' } });
```

Jadikan setiap tujuan atomik: satu hasil yang dapat dipastikan dengan satu
pemeriksaan. Jika dua bagian instruksi masing-masing menghasilkan keadaan yang
perlu diperiksa, pisahkan menjadi dua tujuan. Satu tes dapat memiliki banyak
tujuan.

```ts title="Bad: three goals in one call, no check between them"
await agent.act('open the Pro plan, set the seats to {seats}, and check out', {
  params: { seats: 3 },
});
```

```ts title="Good: one atomic goal per call, arrange, act, assert"
test('checks out the Pro plan', async ({ app, agent, screen }) => {
  await app.open('/plans');
  await agent.act('open the Pro plan');
  await agent.act('set the seats to {seats}', { params: { seats: 3 } });
  await agent.waitFor('the cart shows the Pro plan with 3 seats');

  await agent.act('check out');

  await expect(screen.getByText('Order confirmed')).toBeVisible();
});
```

Tuliskan tujuan persiapan terlebih dahulu dan akhiri dengan menunggu keadaan
yang dituju. Setelah itu tulis tujuan yang diuji, lalu letakkan assertion atas
hasilnya paling akhir. Jika gagal, laporan akan menyebut tujuan yang bermasalah.
Setiap tujuan diputar ulang dari rekamannya sendiri dan memiliki
[anggaran](/reference/agent#budgets) pemanggilan model serta tindakan sendiri.
Tindakan untuk mencapai satu hasil bukanlah tujuan terpisah: membuka layar atau
menu yang memuat kontrol, menggulir ke sana, menutup banner, atau mengisi kolom
dalam satu formulir.

- Anda menentukan urutan tujuan. Agent memilih tindakannya.
- Akhiri tes dengan `expect` atas hasilnya. [Cache replay](/cache) merekam
  tujuan hanya setelah pemeriksaan atau penantian berikutnya berhasil.
- Gunakan kata-kata yang tampil di layar.
- Berikan data tes melalui `params`. Untuk password, berikan `Secret`. Model
  tidak menerima nilainya sebagai teks. Lihat [Autentikasi](/authentication).
- Untuk nilai yang berubah setiap kali tes dijalankan, gunakan `unique()` agar
  [cache dapat memutar ulang langkahnya](/cache#what-must-match):

```ts
import { unique } from 'e2e';

const email = `ada+${Date.now()}@example.test`;
await agent.act('sign up with email {email}', { params: { email: unique(email) } });
```

`act` mengambil screenshot jika diperlukan. Pada beberapa engine, agent dapat
mengetuk dan mengetik pada titik tertentu di gambar.

Jika tujuan gagal, baca laporan dan buat instruksinya lebih spesifik.
Masukkan istilah yang digunakan banyak tujuan ke dalam [`context`](/agents)
milik agent.

## Assertion

Assertion menilai tampilan layar. Model melihat pernyataan, snapshot teks layar
saat ini yang sudah disamarkan, lokasinya, dan konteks agent. Model tidak
melihat langkah sebelumnya atau ringkasan `act`.

- `agent.assert` memeriksa layar saat ini. Pernyataan yang salah gagal dengan
  `ASSERTION_FAILED`. Jika bukti tidak cukup, hasilnya
  `ASSERTION_INCONCLUSIVE`.
- `agent.waitFor` menunggu sampai kondisi terpenuhi. Model hanya dipanggil
  ketika layar atau lokasinya berubah.
- `agent.extract` membaca data dari layar ke dalam tipe
  [Standard Schema](https://standardschema.dev), misalnya Zod.

```ts
import { expect } from 'e2e';
import { z } from 'zod';

await agent.assert('the dashboard shows a trial badge');
await agent.waitFor('a download link appears', { timeout: 120_000 });
await agent.assert('the chart trends upward', { vision: true });

const data = await agent.extract('every todo title', {
  schema: z.object({ titles: z.array(z.string()) }),
});
expect(data.titles).toContain('Buy milk');
```

Untuk teks yang ditulis model, periksa maknanya, bukan seluruh kalimatnya.
Jika teks harus persis, gunakan [locator](#locators).

Untuk pemeriksaan visual seperti grafik atau tata letak, tambahkan
`vision: true`. Untuk menilai screenshot saja, gunakan `vision: 'only'`.
Gambar menambah token input. Lihat [referensi agent](/reference/agent#vision).

## Locator

Locator menemukan kontrol yang sudah diketahui tanpa memanggil model.
Gunakan locator saat tindakan atau nilainya sudah pasti.

```ts
// Role and name first, label second, test ID last.
await screen.getByRole('button', 'Sign in').tap();
await screen.getByLabel('Email').fill('ada@example.test');

// Scope into a row.
const row = screen.getByRole('listitem').filter({ hasText: 'Design review' });
await row.getByRole('button', 'Archive').tap();

// Gestures and coordinates.
await screen.swipe({ direction: 'up' });
await screen.getByRole('image', 'Seat map').tap({ position: { x: 120, y: 48 } });

// Assertions retry until they pass or time out.
await expect(screen.getByRole('status')).toHaveText('2 remaining');
```

- Tindakan, pembacaan, atau assertion untuk satu node gagal jika query-nya
  menemukan lebih dari satu node. Gunakan `.filter()`, `.first()`, atau
  `.nth()` untuk memilih satu node.
- Pembacaan langsung seperti `textContent()` menunggu hasil yang cocok, lalu
  membaca satu kali dan tidak mencoba ulang untuk mendapatkan nilai.

Lihat [referensi screen](/reference/screen) dan
[referensi expect](/reference/expect#locator-matchers). Untuk route, cookie,
dialog, dan unduhan, lihat [Bekerja dengan browser](/browser).

## Susun tes

```ts
import { beforeEach, describe, test } from 'e2e';

describe('billing', { tags: ['billing'] }, () => {
  beforeEach(async ({ app }) => { await app.open('/billing'); });

  test('upgrades', { retries: 2, timeout: 60_000 }, async ({ agent }) => {
    await agent.act('upgrade to Pro');
  });
});

test('needs two organizations', async ({ app }) => {
  test.skip((await countOrganizations()) < 2, 'nothing to switch to');
  await app.open('/organizations');
});
```

- Setiap tes berjalan dalam attempt sendiri. Mulai dari layar yang diperiksa
  agar setiap eksekusi tidak perlu mengulang klik untuk menuju ke sana.
  Siapkan data melalui fixture atau hook. Di browser, pulihkan
  [sesi tersimpan](/authentication) lalu buka layar melalui jalurnya. Di
  perangkat, buka
  [deep link](/mobile#the-device-fixture).
- `test.skip(condition, reason)` menghentikan tes dengan status `skipped` jika
  kondisinya bernilai true.
- Untuk alur yang mencakup banyak tes, tetapkan `{ serial: true }` pada grup.
  Tes berjalan berurutan pada satu worker dan dicoba ulang bersama-sama.
- Gunakan `test.extend` untuk persiapan dan pembersihan. Lihat
  [Menulis fixture](/fixtures).
- Impor `test` dari `@e2e-dev/web`, `@e2e-dev/mobile`, atau
  `@e2e-dev/desktop` untuk memberi tipe pada fixture `browser`, `device`, atau
  `desktop`.

Semua opsi dijelaskan di [referensi test](/reference/test).

## Jalankan satu tes

<CodeGroup>
```bash npm
npx e2e run tests/signup.e2e.ts:12   # the test at line 12
npx e2e run --grep checkout          # tests with a matching title
npx e2e run --target web             # one target
```

```bash pnpm
pnpm exec e2e run tests/signup.e2e.ts:12   # the test at line 12
pnpm exec e2e run --grep checkout          # tests with a matching title
pnpm exec e2e run --target web             # one target
```

```bash bun
bunx e2e run tests/signup.e2e.ts:12   # the test at line 12
bunx e2e run --grep checkout          # tests with a matching title
bunx e2e run --target web             # one target
```
</CodeGroup>

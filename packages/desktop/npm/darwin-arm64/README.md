# @e2e-dev/desktop-darwin-arm64

The macOS arm64 build of the native driver of
[`@e2e-dev/desktop`](https://www.npmjs.com/package/@e2e-dev/desktop), the
desktop engine for `e2e`. npm installs it with `@e2e-dev/desktop` on a Mac
with this architecture; nothing imports it directly.
